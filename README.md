# Asset Booking Portal

## Project Overview
The Asset Booking Portal is a web application developed using Java Spring Boot and MySQL.

It allows users to book shared assets such as meeting rooms, laptops, and projectors.

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

## Planned Modules
1. Asset Management
2. Booking Management
3. Calendar View
4. Booking History
5. Admin Panel
6. AI Booking Assistant
7. Asset Utilisation Report

## Project Status
Currently in the planning and requirements analysis phase.
